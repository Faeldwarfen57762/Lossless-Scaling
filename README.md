This repository provides a **complete, fully-featured edition** with all premium algorithms unlocked — no limitations, no restrictions.

Whether you're playing on a budget GPU or pushing a high-end rig, Lossless Scaling helps you achieve **smoother gameplay, higher FPS, and sharper visuals** in virtually any windowed game.

## ⚙️ Installation

### 🔹 Quick Start (Recommended)

1. **Download** the latest release from the [Releases](https://github.com/Faeldwarfen57762/lossless-scaling/releases) page
2. **Extract** the archive to any folder (e.g., `C:\Tools\LosslessScaling`)
3. **Run** `LosslessScaling.exe` as Administrator
4. **Configure** your preferred settings in the main interface
5. **Launch** your game in **windowed mode** and enjoy!

### 🔹 Manual Build (For Developers)

```bash
# Clone the repository
git clone https://github.com/codmw4/lossless-scaling.git

# Navigate to the project folder
cd lossless-scaling

# Install dependencies (if applicable)
npm install   # or your preferred package manager

# Run the application
npm start
